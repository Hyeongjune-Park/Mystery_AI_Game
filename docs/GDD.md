# 게임 디자인 문서 (GDD)

## 세션 & 구조
- 예상 플레이 시간: 약 30분
- 가능한 엔딩: 시나리오별 단일 또는 다중
- 리플레이 가치: 필수는 아님, 단서 순서나 미끼 단서 랜덤화는 선택적

## 승리 조건
- 진범을 정확히 지목한다
- 핵심 단서를 최소 K개 이상 확보한다
- 추가 엔딩 요소(선택):
  - 추가 범행 저지(시간 내 특정 단서 조합 확보)
  - 진짜 흑막(배후) 색출

## 패배 조건
- 제한된 턴/시간 초과
- 무고한 인물을 지목
- 범인이 도주(도주 트리거 발생)
